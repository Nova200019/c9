# ☁️ Cloud9

Cloud9 is a cloud-based file storage and sharing platform that allows users to store, access, and share various file types securely. It also includes support for digital signing and public hosting of certificates.

## 📌 Introduction

Cloud-9 enables users to:
- Upload and store any file type.
- Access files using built-in emulators and viewers.
- Share files through secure signed links or QR codes.
- Publicly host and digitally sign PDF certificates.
- Distribute documents via email securely.

---

## 📦 MVP (Minimum Viable Product)

The MVP aims to test the essential functionality and core user value.

### ✅ Features in MVP
- User authentication (Login interface).
- Traditional folder-based UI for file management.
- File uploads and access through basic viewers (PDF, images, video).
- File sharing via generated secure links.
- AI aided smart file search



### 🎯 Purpose
To validate:
- Core user flows (upload, view, share).
- Technical feasibility of embedding viewers.
- Interest in public digital certificate hosting.

---

## 💼 Use Cases

- Personal cloud file storage.
- Secure document sharing with external users.
- Hosting digitally signed certificates (e.g., academic, medical).
- Light cloud hosting for multimedia files.
- Easily find pdf or images from file dump.

## 🛠️ Tech Stack

- **Frontend**: React + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: MongoDB / Firebase
- **Authentication**: Firebase Auth or JWT
- **Storage**: Local (MVP) or AWS S3 or Azure Blob (Production)
- **PDF Viewer**: PDF.js
- **Video/Image Players**: Native HTML5 players
